## 🧩 Challenges I Faced & How I Solved Them

During this project, I ran into several real technical issues that deepened my practical understanding:

- **SQL Server not installed**: Had to install SQL Server Express and SSMS from scratch on Windows.
- **Connection failures (SocketTimeoutException)**: Diagnosed and fixed by enabling the SQL Server Browser 
  service and TCP/IP protocol in SQL Server Configuration Manager.
- **Schema vs Database confusion**: Learned the key architectural difference between MySQL (where schema = database) 
  and SQL Server (where schemas exist inside a database), which shaped my final architecture decision.
- **Data type mismatches**: Fixed syntax errors caused by using MySQL-style data types (e.g., `DOUBLE`) 
  instead of SQL Server's equivalent (`FLOAT`).

These challenges gave me hands-on debugging experience beyond just following the tutorial.
